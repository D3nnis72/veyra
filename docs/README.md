# Veyra Documentation

Veyra is a calm visual focus cockpit and self-hostable TypeScript server paired with the `veyra` CLI for conversational workflows in T3 Code.

## Start Here

- Product vision, seven principles, and non-goals: [VISION.md](VISION.md)
- Human setup, commands, and deployment guides: [human/overview.md](human/overview.md)
- Canonical architecture, behavior, and interface rules: [knowledge/README.md](knowledge/README.md)
- Agent routing manifest and context map: [agent/manifest.json](agent/manifest.json) and [agent/context-map.md](agent/context-map.md)
- Open post-MVP gaps and follow-ups: [agent/gaps.md](agent/gaps.md)

## Quick Commands

```bash
pnpm install
pnpm typecheck && pnpm build && pnpm test
pnpm dev:desktop
```
