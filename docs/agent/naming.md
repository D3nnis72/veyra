# Naming Conventions

- Documentation language: English (`docs/` root).
- File and folder names outside `docs/tmp/` and `docs/playbook/`: lowercase ASCII kebab-case (`domain-invariants.md`, `http-sse-api.md`). `README.md` is the only uppercase doc exception (legacy `docs/VISION.md` is kept at its established path).
- Knowledge filenames name subject plus aspect in two to four words, specific without their folder, and unique across `docs/knowledge/`.
- Knowledge IDs mirror their path under `docs/knowledge/` with `.` separators (`knowledge/interfaces/http-sse-api.md` → `interfaces.http-sse-api`; `knowledge/interfaces/README.md` → `interfaces`).
- Human view IDs mirror `docs/human/` (`human/setup.md` → `human.setup`).
